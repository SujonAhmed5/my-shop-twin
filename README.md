# QuickCart Shop Website

A responsive, Daraz-inspired demo storefront built with plain HTML, CSS and JavaScript.

## Run locally
1. Download and unzip the project.
2. Open `index.html` in your browser.

## Included
- Responsive header, search bar and navigation
- Category section
- Hero banner
- Flash sale product cards
- Product grid with sample prices and ratings
- Add-to-cart counter and search interaction
- Offers, service highlights and footer

## Before using in production
This is a front-end demo. Connect a backend/database, real product images, authentication,
checkout/payment provider, order management and delivery integration before accepting orders.
Replace sample contact links and product data in `index.html`.

## Publish on GitHub Pages
1. Create a repository at https://github.com/new
2. Upload `index.html` and this `README.md`.
3. In repository Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`.
4. Save. GitHub will provide your public website URL.
